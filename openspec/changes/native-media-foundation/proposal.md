# Native media foundation

## Why

Desktop authoring applications need real native attached-media rendering/playback while retaining their own project/data authority. The first independently qualified slice supplies actual image/PDF rasters; original audio/video/source-segment workflows remain required continuation work.

## What changes

Create a narrow reusable Rust provider and egui projection. Verify immutable source identity and bounded decode requests, expose real raster/page diagnostics and cancel stale work. Keep original assets unchanged. Qualify library semantics separately from host UX and OS playback.
